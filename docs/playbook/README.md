# Neighbourhood pilot playbook

This is the **process** documentation for running a neighbourhood solar
and home energy pilot — not the technical documentation for forking the
website. If you're looking to set up the site itself, see
[README-build.md](../../README-build.md) or [FORK-WITH-AI.md](../../FORK-WITH-AI.md).

These docs are written as if someone in a different city — Kingston,
Halifax, wherever — is starting cold with no relationship to the Ottawa
pilot, and needs to know what actually happens between "a few neighbours
are curious" and "a group of homes has signed contracts with a vetted
installer."

**Status:** early draft, based on general best practice for group-buy /
cohort-based home retrofit programs, not yet fully validated against a
complete Ottawa pilot cycle. Treat the specifics (numbers, timelines,
exact wording) as a starting point to adapt, not a proven formula. If
you run a pilot using this and learn something that contradicts what's
written here, please open an issue or a PR — that's exactly the kind of
correction this playbook needs.

## Why this is separate from the public site

The [live site](https://mgifford.github.io/neighbourhood-solar/) is
resident- and contractor-facing: it explains the pilot and gets people
to sign up. This playbook is organizer-facing: it's for the person (or
small group) actually running the cohort. Mixing the two would clutter
the resident-facing pages with process detail visitors don't need, so
this lives in `docs/` and is not built into `_site/`.
